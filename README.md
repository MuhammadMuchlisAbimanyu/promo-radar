# Promo Radar

Asisten promosi satu halaman: teks siap salin, antrean target, catatan komunitas, dan banyak produk.
Tidak memposting apa pun otomatis; kamu yang menempel dan menekan kirim.

Data (produk, komunitas, catatan) tersimpan hanya di browser. Salin cadangan dari tab Catatan secara berkala.
Jangan masukkan data sensitif.
